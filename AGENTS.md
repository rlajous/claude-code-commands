# Git Workflow contributor guidance

This repository ships the same workflow skills to Claude Code and Codex. Keep shared instructions host-neutral and preserve compatibility for both runtimes.

## Source of truth

- `skills/*/SKILL.md` contains the 19 shared workflow skills and their canonical bundled resources.
- `agents/*.md` contains the eight canonical agent instructions.
- `.codex/agents/*.toml` is generated by `node scripts/generate-codex-agents.mjs`; never edit those files by hand.
- `.git-workflow/config.yaml` and `.git-workflow/` state files are canonical. Read matching legacy `.claude/` files only as backward-compatible fallbacks.
- `hooks/review-commit.sh` is shared. Host-specific registration lives in `hooks/claude-hooks.json` and `hooks/hooks.json`.

## Runtime conventions

- Document Claude invocation as `/skill-name` and Codex invocation as `$skill-name`.
- Describe actions such as asking the user, searching the web, or delegating without naming host-specific tools.
- Resolve bundled resources from the absolute path of the loaded `SKILL.md`. Derive the package
  root from that skill directory only for package-wide assets. Accept `PLUGIN_ROOT`, then
  `CLAUDE_PLUGIN_ROOT`, only as verified compatibility fallbacks when a host cannot expose the
  loaded path.
- Keep deterministic helpers in the owning skill's `scripts/` or `assets/` directory. Root
  `scripts/*` entries may be compatibility wrappers, but skills must never silently fall back to
  `/scripts` or use a root wrapper as their canonical implementation.
- Preserve Claude-specific frontmatter where Claude requires it. Codex uses `name` and `description` from each skill plus the generated TOML agent definitions.
- Routine edits stay in the main session. Only review, release validation/version comparison, and sufficiently large QA execution workflows delegate to named agents.

## Validation

Before submitting changes, run:

```bash
bash scripts/validate.sh
```

If canonical agent instructions changed, regenerate and commit their Codex definitions:

```bash
node scripts/generate-codex-agents.mjs
```

See [docs/SUBAGENTS.md](docs/SUBAGENTS.md) for the user-facing agent catalog and [CLAUDE.md](CLAUDE.md) for Claude-specific contributor notes.
